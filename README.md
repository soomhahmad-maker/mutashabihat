# المتشابهات ۞

**رفيقك في ضبط آيات القرآن الكريم**

موقع تفاعلي لضبط متشابهات القرآن الكريم:
- اختر السورة ثم اضغط على أي آية.
- في القسم المقابل تظهر الآيات المشابهة مع اسم السورة ورقمها:
  - **التطابق الكلّي** أولًا ببطاقة ذهبية مميزة.
  - ثم **التشابه الجزئي** في عبارة أو جملة مع تظليل العبارة المشتركة.
- تفسير مختصر موثوق (**التفسير الميسّر**).
- تلاوة باختيارك من **6 مقرئين**: العفاسي • عبد الباسط • الحصري • المنشاوي • المعيقلي • العجمي.
- ثيم ليلي / نهاري، وخط IBM Plex Sans Arabic بأسلوب ثمانية + Amiri Quran للآيات.

## التشغيل محليًا

يكفي فتح `index.html` في المتصفح (يحتاج اتصال إنترنت لجلب النص والتفسير والصوت عبر `api.alquran.cloud`).

## النشر عبر GitHub Pages

الموقع static بالكامل (لا يحتاج build). بعد رفع الملفات إلى GitHub فعّل Pages من:

`Settings → Pages → Deploy from a branch → main / (root)`

## المصادر

- النص العثماني والتفسير الميسّر والتلاوة: `https://api.alquran.cloud` (مجمع الملك فهد).
